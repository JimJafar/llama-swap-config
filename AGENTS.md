# Agent instructions: llama-swap config

## Always commit and push

Standing order from Jim: every change you make in this directory gets committed and pushed to
`origin` (github.com/JimJafar/llama-swap-config) as soon as it's done. Don't ask first, and don't
leave work uncommitted at the end of a task. This directory is outside `~/code`, so unpushed work
exists only on Marvin's disk.

- Commit on `main`, matching the style of the existing commit subjects.
- Commit only files that belong in the repo; check `git status` for stray logs or backups first.
- If a push fails (offline, rejected), say so in your reply rather than leaving it silently unpushed.
